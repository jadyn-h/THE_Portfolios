## Short Summary

This is the Mao Mao Fan Club's portfolio website! This is still under-construction along with this readme, so welcome! 
This website is just our portfolio for things we've made in and outside Hack Club. We want to create an interactive portfolio for 
future clients and we want it to be both unique and fun. We originally did this to gain skill in interactive buttons and UIs. 

## Features

Ava's portfolio is planned to have a American comic-inspired point and click game as a portfolio, while Jadyn is planning a mystery case
file as an introduction to herself and her career. Most of our themes are inspired off of the mystery-romance anime KUSURIYA NO HITORIGOTO or Apothecary
Diaries, which is also where we got "Mao Mao" and our profile picture from! 

## Future

We're planning on expanding the different kinds of interactivity with the buttons and expanding our knowledge and experience.
Art is also a big factor also, as both our portfolios require our own art to be made, which is where our teamwork comes in. We 
plan to continue working together and working on different features on each others' websites.
